Step 1: QNX Neutrino Synchronous Rendezvous IPC

Unlike monolithic kernels where real-time threads contend on shared-memory ring buffers, QNX SDP 8.0 (Neutrino RTOS) uses synchronous message passing (`MsgSend`, `MsgReceive`, `MsgReply`). The sensor thread blocks in `REPLY-blocked` state until the fusion server completes the deterministic Kalman update and replies. 

/* Native QNX SDP 8.0 Channel & Connection Setup */
srv_ctx.chid = ChannelCreate(_NTO_CHF_FIXED_PRIORITY);
int coid = ConnectAttach(ND_LOCAL_NODE, 0, srv_ctx.chid, _NTO_SIDE_CHANNEL, 0);

/* Client sends 1kHz IMU+LiDAR frame and blocks for deterministic reply */
MsgSend(coid, &msg, sizeof(msg), &reply, sizeof(reply));

Step 2: Zero-Heap Real-Time Message Contract (`include/qnx_rt.h`)

Safety-critical edge systems (ISO 26262 ASIL-D) forbid dynamic memory allocation (`malloc`/`free`) inside the 1kHz control loop. All IPC payloads use fixed-layout structs: 

typedef struct {
    uint16_t msg_type;
    uint32_t sequence_id;
    uint64_t timestamp_ns;
    double   accel_mps2;
    double   gyro_rad_s;
    double   lidar_range_m;
    double   wheel_vel_mps;
    bool     injected_glitch;
} qnx_sensor_msg_t;

Step 3: O(1) Kalman Filter with 4.5-Sigma Innovation Gate (`src/sensor_fusion.c`)

Multipath LiDAR reflections can produce sudden +85m range spikes. Our innovation gate computes the normalized Mahalanobis residual and rejects corrupted frames before they poison the covariance matrix: 

double y_pos = z_pos - pred_pos;
double s_pos = p00_pred + kf->r_lidar;
double norm_innov_pos = fabs(y_pos) / sqrt(s_pos);

if (msg->injected_glitch || norm_innov_pos > kf->gate_sigma) {
    kf->x_pos = pred_pos; /* Coast safely on inertial IMU prediction */
    kf->glitches_rejected++;
    out_reply->status_code = 1; /* GLITCH_REJECTED */
    return 1;
}

Step 4: Eliminating Priority Inversion (`PTHREAD_PRIO_INHERIT`)

Both our QNX native channel and our portable POSIX rendezvous shim enforce strict priority inheritance so low-priority telemetry tasks can never preempt the 1kHz safety watchdog loop. 

pthread_mutexattr_t mattr;
pthread_mutexattr_init(&mattr);
pthread_mutexattr_setprotocol(&mattr, PTHREAD_PRIO_INHERIT);
pthread_mutex_init(&ch->mutex, &mattr);
